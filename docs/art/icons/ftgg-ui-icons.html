For The Greater Good · UI icons · E-7 resources

Resource and stat icons

The small icons of the HUD and the Codex, in the unit icons' style B: a white glyph with a hairline dark edge and a soft shadow, drawn for 16 px first. Each is one white image tinted in Roblox with ImageColor3, so the match and the Codex keep their own colours (supply white, power amber). One supply mark and one power mark serve both. E-7 draws the resources; the unit stats (E-8) and the weapon stats (E-9) follow on this sheet.

Key list

The tile keys B and D wire; files in assets/2d/ui/

Files: one PNG per key and size, <key>_<size>.png, and one atlas, ftgg-ui-icons.png, holding every tile at every size (one upload); keys.json gives each tile's file and its rectangle in the atlas. Keys follow the Codex's StatBars.GLYPH keys where one exists (time is build time, build will be build power). Rebuild with node assets/2d/tools/ui_icons.mjs; --check fails if a tile is missing or stale.
